# Find Your Job From Heaven — Landing Page

Landing page webinar dan ebook **Find Your Job From Heaven** dari STIFIn Institute, untuk lima Mesin Kecerdasan STIFIn.

## Struktur

```
index.html          Halaman lengkap dalam satu file (gaya, animasi, dan script sudah di dalamnya)
assets/
  logo-stifin.png   Logo STIFIn Institute
  logo-jfh.png      Logo Job From Heaven (versi mendatar)
```
